# ALX GraphQL Project 0x00 — Rick and Morty Queries

## 📘 Project Overview

This project explores the fundamentals of querying data using GraphQL.  
Using the [Rick and Morty GraphQL API](https://rickandmortyapi.com/graphql), we fetch characters and episodes information.

---

## 🧠 Learning Objectives

- Understand how to query data with GraphQL.
- Use arguments such as `id` and `page` to retrieve specific data.
- Structure query results and export them as JSON.
